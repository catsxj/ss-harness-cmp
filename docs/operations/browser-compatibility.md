# 浏览器兼容性

> Vue 3 放弃了 IE11 支持，需确认用户群体

---

## Vue 3 浏览器支持

| 浏览器 | 最低版本 |
|--------|---------|
| Chrome | 64+ |
| Firefox | 78+ |
| Safari | 12+ |
| Edge | 79+（Chromium 内核） |
| IE | **不支持** |

## 迁移前确认

```
[ ] 确认无 IE11 用户（或已通知 IE 用户升级浏览器）
[ ] 确认内网环境的浏览器版本满足要求
[ ] csc-web（保持 Vue 2，独立仓库维护）仍可在 IE11 中使用（如需要）
```

## 注意事项

- Vue 3 使用 Proxy（ES6），无法 polyfill 到 IE11
- Element Plus 同样不支持 IE11
- 如果必须支持 IE11，该子应用不能迁移到 Vue 3
