## 目录结构

```
knowledge-base/
├── README.md              # 本文件（索引）
├── vue3-migration/         # Vue 3 迁移相关
├── element-plus/           # Element Plus 相关
├── echarts/                # ECharts 相关
├── qiankun/                # Qiankun 微前端相关
├── typescript/             # TypeScript 相关
├── third-party-libs/       # 第三方库替换方案
└── troubleshooting/        # 问题排查记录
```

## 文件命名规范

```
{分类}/{日期}-{关键词}.md

示例：
  vue3-migration/2026-04-20-composition-api-vs-options.md
  element-plus/2026-04-20-dialog-visible-sync.md
  troubleshooting/2026-04-20-echarts-data-undefined.md
```

## 文件内容格式

```markdown
# {问题标题}

## 问题描述
遇到了什么问题，错误信息是什么

## 原因分析
为什么会出现这个问题

## 解决方案
具体怎么修复

## 参考资料
- [链接1](url) — 简要说明
- [链接2](url) — 简要说明

## 适用范围
哪些子应用/场景会遇到此问题
```
